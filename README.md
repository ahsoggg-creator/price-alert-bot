# Telegram-бот: уведомление о снижении цены

Бот следит за ценами на товары по ссылкам и присылает сообщение, когда цена опускается до нужной. Удобно, если ждешь скидку и не хочешь каждый день проверять сайт руками.

## Команды

- `/add <ссылка> <цена>` - добавить товар и цену, которую ждешь
- `/list` - список товаров с текущей ценой
- `/del <номер>` - удалить товар
- `/check` - проверить цены прямо сейчас

Цены проверяются автоматически раз в час (интервал настраивается). Уведомление приходит один раз, когда цена стала ниже нужной. Если потом цена снова поднимется и опять упадет - придет еще одно.

## Какие сайты поддерживаются

- books.toscrape.com - для примера и проверки
- сайты, где цена есть в разметке товара (schema.org Product / микроразметка) - это многие интернет-магазины

Для конкретного магазина можно дописать свою функцию разбора страницы и добавить ее в словарь `SHOPS` в `prices.py`.

## Установка

Нужен Python 3.10+

```
pip install -r requirements.txt
```

1. Создать бота у [@BotFather](https://t.me/BotFather) командой `/newbot` и скопировать токен
2. Скопировать `.env.example` в `.env` и вставить токен:

```
BOT_TOKEN=123456:ABC...
CHECK_INTERVAL_MINUTES=60
```

## Запуск

```
python bot.py
```

Дальше открыть своего бота в Telegram, нажать Start и добавить товар, например:

```
/add https://books.toscrape.com/catalogue/sharp-objects_997/index.html 50
```

Товары хранятся в файле `items.db` (SQLite) рядом с ботом, после перезапуска ничего не теряется.

## Если бот не подключается к Telegram

Если в консоли ошибки подключения к api.telegram.org, можно указать прокси в `.env`:

```
PROXY=http://user:pass@host:port
```
