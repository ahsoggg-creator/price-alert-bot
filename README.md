# price-alert-bot

Telegram-бот, который следит за ценой товара и пишет, когда она опускается до нужной. Кидаешь ссылку и цену - дальше бот сам проверяет сайт раз в час.

Команды:

```
/add <ссылка> <цена>   добавить товар
/list                  что отслеживается и текущие цены
/del <номер>           удалить
/check                 проверить прямо сейчас
```

Уведомление приходит один раз, когда цена стала ниже нужной, а не каждый час подряд. Если цена потом вернется выше и снова упадет - придет еще раз. Товары хранятся в SQLite (`items.db`), после перезапуска ничего не теряется.

Цена берется из микроразметки товара (schema.org), она есть у многих магазинов. Если у конкретного сайта ее нет - пишется своя функция разбора и добавляется в `SHOPS` в `prices.py`, для примера там уже есть books.toscrape.com.

## Запуск

Токен берется у [@BotFather](https://t.me/BotFather), дальше:

```
pip install -r requirements.txt
copy .env.example .env
python bot.py
```

В `.env` вписать `BOT_TOKEN`. Там же можно поменять интервал проверки (`CHECK_INTERVAL_MINUTES`) и указать `PROXY`, если api.telegram.org у провайдера не открывается. Формат `http://логин:пароль@ip:порт` или `socks5://...`, если схему не написать - будет http.

Проверить можно так:

```
/add https://books.toscrape.com/catalogue/sharp-objects_997/index.html 50
/check
```
